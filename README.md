# ⏳ Time Capsule

موقع **Time Capsule** هو مشروع بسيط لفكرة كبسولة زمنية رقمية.

## 💡 الفكرة
يسمح لك بحفظ رسائل وذكريات لمستقبلك، وفتحها لاحقًا في وقت تختاره.

## 🌐 الموقع
هذا المشروع عبارة عن صفحة ويب بسيطة تعمل على GitHub Pages.

## 🚀 الهدف
تجربة فكرة حفظ الذكريات بطريقة رقمية حديثة.

## ✨ ملاحظة
المشروع ما زال قيد التطوير وسيتم إضافة ميزات جديدة قريبًا.
